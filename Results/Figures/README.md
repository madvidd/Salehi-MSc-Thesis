# Research Figures

This collection contains the 23 numbered research figures and graphical abstract used in the current report. Assets are unchanged copies of the final figure masters and matching exports. Figure numbers provide a direct route from the report; descriptive paths remain independent of pagination.

- **SVG**: editable, resolution-independent master.
- **PDF**: matching vector export for print and scientific typesetting.
- **PNG**: convenient preview; use a vector format for publication.

[Visual gallery](Gallery.md) | [CSV index](Figure_Index.csv) | [File manifest](Manifest.json) | [SHA-256 checksums](SHA256SUMS.txt)

Architecture schematics and study comparisons are kept separate. Accuracy and training-time plots remain distinct within each matched study. University branding, superseded drafts and reserved-result placeholders are excluded. No report source or compiled dissertation is included.

## Verification and Interpretation

Run `python Tools/Figures/validate_figure_collection.py` from the repository root. The check verifies the index, formats, file sizes, SHA-256 digests and supporting-record paths without starting training.

A plotted checkpoint-selection value is not interchangeable with a final-epoch metric vector. Retained training durations describe their recorded protocols. Follow the linked study records for evaluation identity, configuration and measured values; no cross-study ranking is implied.

The figures are project-specific schematics and analyses. Underlying model attribution remains in [Source Attribution](../../Documentation/Source_Attribution.md); no university logo is redistributed here.
