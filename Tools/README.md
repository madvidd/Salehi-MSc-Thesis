# Repository Utilities

- [Terminal utilities](Terminal/README.md): historical command examples for log
  capture and checkpoint inspection.
- [Repository validator](Repository/validate_repository.py): offline checks for
  layout, local navigation, preserved evidence and Python syntax.
- [Result catalogue builder](Repository/build_results_catalog.py): regenerate
  the current study summaries and CSV tables from retained evidence.

Utilities do not start training unless explicitly documented as launchers.
