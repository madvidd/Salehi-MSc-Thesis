SEAM archive. Large released checkpoints and presentation assets were not copied
into this Git repository.

preprocessing, datamodule, model, metric, and utility sources required for the
Argoverse 2 experiment. Package-specific modifications are documented in
`ARTICLE_AND_CODE_AUDIT.md`.
