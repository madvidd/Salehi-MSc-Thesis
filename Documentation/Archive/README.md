# Historical Documentation

This directory retains the earlier consolidated results index as a dated
record. Its provisional statuses and cross-machine tables have been superseded
by the [current study registry](../../Results/Main/All_Run_Registry.md).

Historical links identify the layout and external evidence available at their
capture date. Use the [path migration index](../Repository_Audit/Path_Migration.csv)
to locate repository files under their current study folders. These documents
are not the authoritative current comparisons.
