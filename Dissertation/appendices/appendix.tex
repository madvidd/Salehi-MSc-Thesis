\section{Final-suite validation checklist}

The following checklist prevents active training values from being promoted into the final result table:

\begin{enumerate}
    \item confirm that all three variant directories contain a completion marker and a loadable \path{last.ckpt};
    \item select the checkpoint with minimum validation minADE6 according to the same rule for every run;
    \item run the final evaluation script on one GPU with batch 32, avoiding DDP validation padding;
    \item obtain MR, b-minFDE6, minADE1, minADE6, minFDE1 and minFDE6 from the generated machine-readable JSON;
    \item verify that the Markdown/CSV table and plotted values match the JSON to six decimal places;
    \item insert the three vectors into Table~\ref{tab:final-pending};
    \item replace the reserved Figure~\ref{fig:final-pending} with the suite's PNG while retaining the SVG alongside it;
    \item update the abstract, conclusion, word count and page count; and
    \item compile twice after BibTeX and inspect every page before submission.
\end{enumerate}

\section{Reproduction caveats}

The word ``reproduction'' is used with explicit qualification in this dissertation. An exact floating-point match is not guaranteed when GPU architecture, CUDA libraries, distributed execution and data-loader order differ. The final baseline is \emph{article-aligned} in architecture and optimisation controls, while the paper's execution used one RTX 8000. The retained earlier Lab 2 baseline is a 60-epoch local reproduction with global batch 16. The Lab 3 attention baseline is an 80-epoch internal control with global batch 24. These are distinct evidence categories.
